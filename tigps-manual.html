資料查詢 · 編號規則

看懂一組 TIGPS ID

ID 分成三段，從左到右依序是組別前綴、流水碼、身分碼。身分碼可以省略，省略就代表學生本人。

s112014364025P1

組別前綴

s112・s113・s114 為追蹤組；s115 為新增組

流水碼

學生本人的編號。同一家庭的成員共用這串數字

身分碼

P＝照顧者，B＝手足；無身分碼即學生本人

結尾身分數量上限
（無）學生本人1 位
P1、P2照顧者每位學生至多 2 位
B1、B2手足每位學生至多 2 位

判斷組別的兩種方式

可以互相對照：看 ID 前綴（s112／s113／s114 追蹤組、s115 新增組），或看「詳細資訊」的就讀學校（有國中為追蹤組、只有高中為新增組）。

作業流程 · 查領獎金額

查某人這一波還能領多少，以及發完獎要做什麼

以「W2 能領多少禮券」為例。整段流程橫跨兩個地方：先在「修改資料」查待領金額，發完獎後回到「問卷填答 & 領獎狀況」更新紀錄。

  1. 開啟查詢視窗在資料查詢頁點「修改資料」→「輸入 Line ID 要查看領獎狀態」。
  2. 輸入 Gosu ID視窗要的是 8 碼的 Line ID，也就是 Gosu ID，輸入後按「提交」。
  3. 看畫面最下方的「待領取獎勵」會列出領獎身份、領獎原因與金額。
  4. 發放獎勵依金額到「允文」資料夾取禮券連結，於獎勵紀錄頁新增紀錄。
  5. 更新領獎狀況回資料查詢頁點該筆 TIGPS ID，把對應波次的領獎狀態改掉並儲存。

最容易出錯的一步

「待領取獎勵」發過之後不會消失

這份清單不會因為你已經發過就自動清掉，所以它顯示有，不代表還沒發。發放前一定要另外確認一次：

  • 到獎勵紀錄頁用 TIGPS ID 或 Gosu ID 查這個人的發放紀錄；
  • 或用依獎勵代碼 1 查詢，貼上禮券連結確認這張沒發過。
  1. 1

    ID 輸入欄

    輸入 8 碼的 Line ID（＝Gosu ID）。

  2. 2

    提交

    送出後顯示該人的領獎狀態。

確認金額後就可以發放。發完之後，回到資料查詢頁點該筆 TIGPS ID，開啟「問卷填答 & 領獎狀況」把紀錄補上。

  1. 1

    ID

    確認一下是不是你要處理的那個人。

  2. 2

    項目

    逐年一列：第一年到第五年，另有 25/3 小測。

  3. 3

    填答狀態

    已填寫／未填寫，改完按右邊的 儲存。

  4. 4

    領獎狀態

    已領取／未領取，改完按右邊的 儲存。

    發完獎一定要回來把這裡改成已領取並儲存，否則下次查詢還是會顯示待領。
  5. 5

    無資料

    該波次沒有領獎資料時顯示，不需處理。

  6. 6

    關閉

    兩欄的儲存是分開的，關閉前確認都按過了。

紙本紀錄 · 頁面總覽

紙本問卷紀錄的九個操作點

這個頁面是一份可直接編輯的待寄／已寄清單。每一列代表一次寄件，右側的狀態欄顯示這筆資料是否已經匯出過。

  1. 1

    匯出 Excel

    匯出目前尚未寄出的寄件資料成 Excel 檔，供列印寄件標籤或建檔使用。已標示「已匯出」的資料不會重複出現在檔案裡。

  2. 2

    回首頁

    離開本頁，回到「資料查詢」頁面（圖 1）。

  3. 3

    收件人姓名

    輸入收件人姓名，用來篩選清單。可只輸入部分姓名。

  4. 4

    搜尋 / 清除

    搜尋 依上方姓名篩出該收件人的所有寄件紀錄；清除 清空條件，回到完整清單。

  5. 5

    可編輯欄位

    收件人、電話、地址、郵寄原因、ID、GOSU ID、備註都可以直接在表格中點入修改，不需另開編輯視窗。

  6. 6

    ID 與 GOSU ID

    要找特定受訪者時，按 Ctrl＋F（Mac 為 Cmd＋F）輸入受訪者 ID 或 GOSU ID，瀏覽器會直接標出對應的資料列。

  7. 7

    是否匯出

    未匯出 尚未寄出，會被下次匯出納入。
    已匯出 已寄出，不再納入匯出名單。

  8. 8

    儲存

    把該列的修改寫入系統。

    修改後一定要按下同一列的「儲存」，否則變更不會生效。
  9. 9

    刪除

    移除整列紀錄。兩種情況會用到：重複建立的資料，或受訪者已改為填寫電子問卷、不需再寄紙本。

    刪除後無法復原，請先確認 ID 再執行。

紙本紀錄 · 作業流程

一次完整的寄件作業

  1. 進入頁面在資料查詢頁點擊導覽列的「紙本紀錄」。
  2. 檢查待寄資料確認收件人、電話、地址、郵寄原因是否正確。
  3. 修改並儲存有任何更動，按下該列的「儲存」。
  4. 清掉不需寄送的紀錄刪除重複資料，以及已改填電子問卷的受訪者。
  5. 匯出名單點「匯出 Excel」，取得本次所有尚未寄出的資料。
  6. 依名單寄送用 Excel 列印標籤並完成寄件。

郵件紀錄 · 頁面總覽

紙本禮券的寄送清單

「郵件紀錄」記錄的是紙本禮券的寄出狀況。與紙本問卷不同的是，這裡的實際寄送作業由廠商執行，本頁主要是查詢與核對用。

先看這裡

本頁的資料異動一律要聯繫廠商

禮券已交由廠商處理，系統上的紀錄不能自行更動就當作完成。下列情況都必須另外通知廠商：

  • 紙本改電子 — 受訪者改領電子禮券時，要請廠商刪除該筆寄送紀錄，避免重複寄出。
  • 修改收件資訊 — 姓名、電話、地址有誤或變更，要通知廠商更正後再寄。
  • 取消或補寄 — 任何影響是否寄出的決定，都以廠商端的紀錄為準。
  1. 1

    匯入郵件編號

    廠商寄出後會回覆一份含郵寄編號的檔案，由此匯入，系統會把編號回填到對應的紀錄上。

  2. 2

    匯出 Excel

    把禮券寄送清單匯出成 Excel，用來提供給廠商或內部核對。

  3. 3

    收件人姓名

    依收件人姓名篩選。

  4. 4

    郵寄原因

    依禮券名目篩選，例如「第四年問卷獎勵300$」、「2026年問卷獎勵」。

  5. 5

    郵寄編號

    用廠商回覆的郵寄編號反查是哪一筆、寄給誰。查件時最常用這個。

  6. 6

    搜尋 / 清除

    三個欄位可以一起用來縮小範圍；清除 回到完整清單。

  7. 7

    下拉選單，標記這筆禮券的寄送狀態。

    改狀態不等於實際攔下或寄出，仍要與廠商確認。
  8. 8

    郵寄編號欄

    廠商寄出後產生的追蹤編號。可用「匯入郵件編號」批次填入，也可單筆手動輸入。

  9. 9

    建立時間 / 最後更新

    紀錄產生的時間與最近一次異動的時間，用來判斷這筆是不是剛改過、或已經擱置多久。

  10. 10

    儲存

    寫入該列的修改。

    修改後要按同一列的「儲存」；若改的是收件資訊，儲存完仍須通知廠商。

郵件紀錄 · 廠商協作

什麼時候要聯繫廠商

判斷原則很單純：只要這筆禮券還沒寄到受訪者手上，而你想改變它的去向或內容，就要通知廠商。

  1. 受訪者改領電子禮券請廠商刪除該筆紙本禮券的寄送紀錄，避免重複發放。
  2. 收件資訊有誤或變更更正姓名、電話、地址後，把正確資訊一併告知廠商。
  3. 需要取消寄送在頁面上調整「是否寄送」的同時，一定要向廠商確認實際是否攔得下來。
  4. 查件或補寄先用「郵寄編號」查到該筆紀錄，再帶著編號與廠商聯繫。

手動新增紙本獎勵 · 頁面總覽

受訪者需要紙本禮券時，在這裡登記

當受訪者要的是紙本禮券而不是電子禮券，就在這一頁登記。登記後，廠商會依照登記的金額幫我們寄送。

登記前後各有一件事一定要做

目前領獎原因只能選「2026年問卷獎勵」

下拉選單目前只有這一個選項，所以系統上看不出這筆實際是為了哪一波、哪一項而發。因此：

  • 登記後要去修改領獎狀況 — 到資料查詢頁點該筆 TIGPS ID，把對應波次的領獎狀態改掉並儲存（圖 8）。

受訪者表示要紙本 → 本頁「新增登記」填金額 → 廠商依金額寄送 → 寄送狀況可在郵件紀錄頁追蹤 → 回資料查詢點 TIGPS ID 更新領獎狀況。任何異動（改地址、取消）都要另外聯繫廠商。
